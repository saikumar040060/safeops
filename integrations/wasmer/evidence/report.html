Scope and limitations

This is a scripted agent/approval demonstration against local owned fixtures, using the actual gateway, PostgreSQL, and Wasmer SDK. It is not a live LLM session. These probes verify specific boundaries, not universal injection detection or a proof against all sandbox escapes. The extension contains only the new analysis tool.

Build disclosure: SafeOps core predates the event (baseline e0a27bc). The Wasmer tool, probes, regression cases, demonstration, and this evidence package are September 13 work.
